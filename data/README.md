# Data

- **Source:** U.S. Lobbying Disclosure Act filings, public LDA API (confirm the current endpoint before collecting).
- **Scope:** filing years 2021–2022 (117th Congress, 3 Jan 2021 – 3 Jan 2023).
- **Unit:** one sentence of a lobbying-activity description that cites a bill number.
- `raw/` holds downloads and is not committed. `processed/` holds the derived CSV files listed in the main README.

Record collection dates, row counts and random seeds here as they are produced.
